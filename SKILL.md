\# TestGen Skill



When a user provides source code:



1\. Identify the programming language and the function being tested.

2\. Understand the expected behaviour from the code and user-provided requirements.

3\. Generate unit tests for normal cases, boundary cases, and invalid inputs.

4\. Use the appropriate testing framework for the language.

5\. Explain how to run the tests.

6\. Never claim tests passed unless they were actually executed and passed.



Keep tests readable, focused, and reproducible.
